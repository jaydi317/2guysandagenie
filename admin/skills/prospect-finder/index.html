The Prospect Finder Skill

The method we used to build the list of local businesses, written so any of our Claudes can run it.

How to add it to your Claude
  1. Tap Copy The Skill below.
  2. Open Claude and start a new chat.
  3. Say: "Make this a skill called prospect-finder" and paste what you copied.
  4. Save the skill when Claude shows it to you.
  5. Then say "run a batch". Before it starts, it checks the "Areas Covered" tab of our Local Business Database sheet, so it never repeats an area or a shop.
